# NeuroStack Documentation

Documentation for NeuroStack, a fictional cloud platform for developing, training, deploying, and monitoring machine learning models.

This is a Docs-as-Code portfolio project demonstrating professional technical writing workflows for cloud and ML platforms.

---

## What is NeuroStack?

NeuroStack is a cloud platform that enables data scientists and ML engineers to:

- Develop ML code in managed Jupyter environments with CPU or GPU resources
- Store datasets and model artifacts in integrated object storage
- Train models on scalable compute resources without managing infrastructure
- Deploy models as REST API endpoints with auto-scaling
- Monitor endpoint health, performance, and resource usage
- Automate workflows through the REST API and CLI
